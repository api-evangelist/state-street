Digital - Token Management Description Token Management API is designed to manage smart contract templates, smart contract deployments, contract calls for different functions like mint, burn, transfer transactions etc, balance query and also support whitelisting of contract addresses. This API supports RESTful endpoints for different entities i.e. templates, smartcontracts, deploy, call, transactions and whitelist.
