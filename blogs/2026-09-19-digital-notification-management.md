Digital - Notification Management Description Notification Management API is designed to manage notifications related to accounts/wallet setup, tokenization of assets, transactions, etc. This API supports RESTful endpoints for publishing and receiving notifications. Consuming systems can make calls to get events data for different operations in digital asset platform.
