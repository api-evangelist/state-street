Custody Corporate Action 4.0 Description This API contains records of voluntary and mandatory corporate action events. Details includes entity information as well as option, entitlement, notification and response. Client Benefits Provides clients with comprehensive, near real‑time visibility into Corporate Action activity, including event details, election responses, and notifications—enabling informed decision‑making and improved operational oversight.
