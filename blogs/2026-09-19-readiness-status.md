Readiness Status Description Readiness Status API is designed to provide a consistent RESTful interface for downstream applications to check FDL readiness status by business name, EOD date, and optional branch. The API returns a unified response envelope across success and error scenarios so clients can process responses with stable parsing logic and predictable codes. The endpoint supports both single-record and list-style results, depending on whether the optional branch parameter is provided.
