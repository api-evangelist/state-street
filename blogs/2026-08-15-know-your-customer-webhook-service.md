Know Your Customer Webhook Service Description Webhook integration APIs is designed to receive all events generated by FenX platform and send events to Kafka topic for downstream processing. This API will return success or failure of webhook events publish to kafka along with the failure message. This API can only be invoked from the FENX Platform and no individual users will be accessing this API.
